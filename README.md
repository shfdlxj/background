# background — 임시 바탕화면

실제 배경화면 설정은 건드리지 않고, **배경화면 위·바탕화면 아이콘 아래**에 이미지를 띄웁니다.
Win+Tab 가상 데스크톱마다 다른 이미지를 보여줄 수 있고, 끄면 원래 배경화면이 그대로 보입니다.

## 요구 사항

- Windows 10 / 11 (Windows 11 24H2 이상에서 확인)
- Windows PowerShell 5.1 (Windows에 기본 포함, 따로 설치할 것 없음)

## 설치

```
git clone https://github.com/shfdlxj/background.git
```

또는 GitHub에서 **Code → Download ZIP**으로 받아 압축을 풉니다.

> ZIP으로 받은 경우 Windows가 "인터넷에서 받은 파일"로 표시해서 실행할 때 경고가 뜰 수 있습니다.
> 압축을 풀기 **전에** ZIP 파일 우클릭 → 속성 → 아래쪽 **차단 해제** 체크 → 확인 후 압축을 푸세요.

## 빠른 시작 (원터치)

1. 이 폴더에 이미지(jpg / png / bmp / gif / tif)를 넣습니다. 예시로 `Picture1.png`가 들어 있습니다.
2. `background.cmd`를 **더블클릭** → 켜짐
3. 다시 **더블클릭** → 꺼짐

이미지는 **파일 이름 순서대로** 데스크톱 1, 2, 3...에 배정됩니다.

- 이미지가 1장이면 모든 데스크톱에 같은 이미지
- 이미지가 데스크톱보다 적으면 나머지 데스크톱(나중에 새로 만든 것 포함)은 **1번 이미지**
- 순서를 확실히 정하려면 `1_산.png`, `2_바다.png`처럼 숫자로 시작하는 이름을 쓰세요.
  10장 이상이면 `01`, `02`...처럼 0을 붙이세요 (`10.png`가 `2.png`보다 앞에 정렬되기 때문).

이미지를 바꾼 뒤에는 더블클릭 두 번(끄고 → 켜기)으로 다시 적용합니다.

## 명령어

cmd에서는 `background ...`, PowerShell에서는 `.\background ...`로 실행합니다.

| 명령 | 동작 |
|---|---|
| `background` | 원터치와 같음 (켜져 있으면 끄기) |
| `background 사진.png` | 모든 데스크톱에 표시 |
| `background 2 바다.png` | 데스크톱 2에만 표시 (번호는 Win+Tab 화면 왼쪽부터 1) |
| `background 2 off` | 데스크톱 2 설정만 지우기 |
| `background list` | 현재 설정 보기 (`*` = 지금 있는 데스크톱) |
| `background off` | 전부 끄기 |

켜져 있는 상태에서 명령을 실행하면 다시 켤 필요 없이 바로 반영됩니다.

### 표시 방식 `-Mode`

`background 사진.png -Mode fit`처럼 뒤에 붙입니다.

| 값 | 동작 |
|---|---|
| `fill` (기본) | 화면을 꽉 채움, 비율이 남는 부분은 잘림 |
| `fit` | 사진 전체가 보이게, 남는 곳은 검은색 |
| `stretch` | 비율 무시하고 화면에 맞게 늘림 |
| `center` | 원본 크기 그대로 가운데 |

모니터가 여러 대면 모니터마다 각각 위 방식으로 그립니다. 휴대폰 사진의 회전 정보(EXIF)도 반영합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `background.cmd` | 시작 버튼. 인자 없으면 켜기/끄기 토글, 인자가 있으면 `background.ps1`에 그대로 전달 |
| `background.ps1` | 본체. 앞부분은 명령 처리(설정 저장, 프로세스 켜기/끄기), 뒷부분은 화면에 그리는 C# 코드 |
| `desktops.txt` | 데스크톱별 이미지 설정 (켤 때 생기고 끄면 지워짐). 한 줄 = `데스크톱ID<TAB>표시방식<TAB>이미지경로`, `*`는 나머지 전부 |
| `%TEMP%\temp-background.pid` | 숨어서 실행 중인 프로세스 번호 (끌 때 사용) |

## 동작 방식

1. **끼워 넣기**: 바탕화면 창(Progman) 안에서 아이콘 층(`SHELLDLL_DefView`) 바로 아래, 배경 층(`WorkerW`) 위에 창을 붙입니다.
   실제 배경 층은 덮기만 하므로 설정이 바뀌지 않습니다.
2. **상주**: 실행하면 자기 자신을 숨겨진 PowerShell 프로세스로 하나 더 띄워 계속 남겨 둡니다.
3. **감시 (0.3초마다)**
   - 바탕화면 창이 사라졌으면(탐색기 재시작) 종료, 창이 떨어졌으면 다시 붙임
   - `desktops.txt`가 바뀌었으면 다시 읽음
   - 레지스트리 `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\VirtualDesktops\CurrentVirtualDesktop`에서 현재 데스크톱 확인
4. **선택**: 현재 데스크톱 설정 → 없으면 `*` 설정 → 그것도 없으면 창을 숨겨 원래 배경화면 표시
5. **캐시**: 데스크톱마다 처음 한 번만 화면 크기로 그려 두고, 다시 돌아오면 바로 꺼내 씁니다.

## 자원 사용량 (2880×1800 화면에서 측정)

| 항목 | 값 |
|---|---|
| CPU | 전체의 약 0.02% |
| 메모리 | 약 63MB(PowerShell 자체) + 사진 1장당 약 20MB |
| GPU / 디스크 / 네트워크 | 사실상 0 |

## 주의할 점

- **데스크톱 전환 시 깜빡임**: 0.3초마다 확인하므로 전환 직후 이전 이미지가 최대 0.3초 보일 수 있습니다.
- **Windows 업데이트**: 현재 데스크톱을 읽는 레지스트리 값은 공식 API가 아니라서, 업데이트 후 데스크톱별 전환이 안 될 수 있습니다.
- **수정할 때 인코딩**: `background.ps1`은 반드시 **UTF-8(BOM)**으로 저장하세요. BOM 없이 저장하면 Windows PowerShell 5.1에서 한글이 깨집니다.
- **재부팅**: 재부팅하면 꺼집니다. 다시 켜려면 더블클릭하세요.
- **이미지는 커밋되지 않음**: `.gitignore`가 예시 이미지(`Picture1.png`) 외의 이미지와 `desktops.txt`를 제외합니다.
